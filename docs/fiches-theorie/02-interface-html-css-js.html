L’interface : HTML, CSS et JavaScript

Une page web est composée de couches qui collaborent, mais qui n’ont pas le même travail.

TechnologieQuestion à laquelle elle répondExemple
HTMLQuels éléments et quelle structure ?Un titre, une liste, un formulaire, une étiquette.
CSSComment présenter ces éléments ?Couleurs, espacement, colonnes, adaptation mobile.
JavaScriptComment réagir sans reconstruire toute la page ?Donner le focus au champ, afficher un état, dessiner dans Canvas.
PHPQue doit préparer ou vérifier le serveur ?Lire un projet dans MySQL et produire du HTML.

HTML : donner un sens aux commandes

Un <label> nomme un champ ; un <button> déclenche une action ; un lien <a> navigue vers une autre adresse. Utiliser le bon élément améliore aussi l’usage au clavier et par les technologies d’assistance.

Le focus indique quelle commande recevra la prochaine action clavier. Avec Tab, on avance ; avec Maj + Tab, on revient. Le contour du focus doit rester visible.

jQuery et JavaScript natif

jQuery simplifie certaines interactions et AJAX : dans ce projet, app.js écoute les formulaires et api.js centralise les échanges avec PHP. Les scripts sont chargés dans cet ordre : jQuery, api.js, puis app.js, avec defer.

Le moteur de mosaïque et Canvas restent en JavaScript natif. jQuery n’a pas à remplacer l’algorithme fourni du prototype.

HTML décrit → CSS présente → JavaScript réagit → PHP valide et prépare les données

Une amélioration progressive

  1. Construire le formulaire HTML avec un vrai label et un bouton.
  2. Tester l’écran dans le navigateur après l’avoir enregistré.
  3. Ajouter une interaction ciblée dans app.js.
  4. Vérifier souris, clavier, écran étroit et messages d’erreur.

Phrase pour l’expliquer

« HTML donne sa structure et son sens à la page, CSS règle son apparence, JavaScript gère les interactions dans le navigateur. PHP travaille sur le serveur et peut fournir les données à la page. »
