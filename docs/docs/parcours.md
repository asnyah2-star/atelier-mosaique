# Le parcours de l'atelier

[Accueil](../README.md) · [Commencer la mission 1](missions/01-atelier-github.md)

Ton fil rouge : partir d'une démonstration, puis lui ajouter une mémoire et des
projets séparés. Le parcours s'appuie sur tes bases HTML/CSS et introduit PHP,
SQL et Git à mesure qu'ils deviennent utiles. Nous pourrons reprendre une notion
ensemble quand tu en auras besoin.

Tu utiliseras jQuery pour les interactions dès la mission 3. Fais ensuite marcher
ton premier formulaire PHP en mission 4, puis découvre les requêtes AJAX en
mission 5 : elles permettent d'échanger avec PHP sans recharger toute la page.
Le fichier `api.js` regroupera ces échanges ; `app.js` pilotera l'interface.

## Une routine légère

Avant de commencer, récupère les nouveautés avec GitHub Desktop. Lis le but de ta
mission. Avance par étapes, observe le résultat et consulte les pistes selon tes
besoins. Vérifie les cas de réussite **et** le cas d'erreur proposé.

À la fin d'une étape, relis les fichiers modifiés, fais un commit ciblé et envoie-le.
Note ta prochaine action dans le [journal](journal.md). Complète le
[guide de transmission](transmission.md) dès que tu découvres un prérequis ou une
manipulation utile. Si nos modifications entrent en conflit, préviens-moi : nous
les comparerons avant de poursuivre.

## Préparer une question utile

Prépare trois éléments : ce que tu voulais obtenir, ce que tu observes et ce que
tu as déjà essayé. Partage une erreur débarrassée de toute donnée sensible.
Une IA peut expliquer une notion ou relire quelques lignes que tu as écrites.
Demande un indice à la fois, puis reformule ce que tu as compris.

## Ce qui peut attendre

Les branches et pull requests, la suppression complète d'un projet, le
glisser-déposer et les optimisations sont des bonus. Tu n'as pas à créer des
comptes utilisateurs dans l'application. Le laboratoire OVH reste facultatif.
Le premier objectif est une application locale compréhensible et partageable.
